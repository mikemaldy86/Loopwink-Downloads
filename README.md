# Loopwink downloads

Official downloads for Loopwink, Clickwink and Movewink from Monty Moo Studios.

**Downloads are not published yet.** This repository currently hosts the update list only.

- Clickwink and Movewink are always free.
- Loopwink keeps its existing free and licensed features. Downloading it does not unlock paid features.
- Beta releases are unfinished test versions. Use the release notes to choose the correct Windows, Intel Mac or Apple Silicon Mac download.

This is a downloads-only repository. Application source and private licence signing keys are kept separately.

Updates are checked only when you choose **Check for updates** in the app. Loopwink places it in Settings → Help; standalone Clickwink and Movewink place it on the main screen. The app checks the public update list and offers the matching release page. It does not install updates automatically or upload recordings, settings or licence information. GitHub receives ordinary download requests.

Older installed versions need one manual installation of an update-enabled build before this feature appears.
